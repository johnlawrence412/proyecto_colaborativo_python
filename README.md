# 🧩 Proyecto Colaborativo en Python

## 🧾 Enunciado
Este proyecto tiene como objetivo crear un **repositorio colaborativo en GitHub** donde un equipo de desarrollo trabaje conjuntamente en un proyecto en **Python**.  
El proyecto incluye al menos tres módulos con funcionalidades distintas, y cada miembro del equipo contribuye a la creación y mejora de alguna parte del código.

---

## ⚙️ 1. Configuración del Repositorio
- Se creó el repositorio en GitHub bajo el nombre **`proyecto_colaborativo_python`**.  
- Se configuró el entorno de desarrollo en **Visual Studio Code** y se conectó correctamente con GitHub.  
- Se verificó la ejecución del proyecto localmente utilizando **Python 3.14.0**.
